当前数据缺少真实日涨停价，因此涨停策略以确定性本地样例验证，未声称在全量真实行情上验证了涨停覆盖。包含9.97%左右涨幅但收盘价等于涨停价的案例；真实资料需用户另行提供。

## 证券快照与边界

证券表6165条代码记录：上海2466条、深圳3094条、北京605条（含历史代码）。上海148条、深圳189条、北京2条确认退市，北交所其余603条状态未知。来源证据见 `resources/security_metadata.json`，不能宣称已完整核实北交所上市状态。

Windows 文件名为 `股票分析.exe`，使用 K 线图标。菜单栏提供语言切换、独立帮助和简短关于信息；界面分为设置、策略和结果三部分。CLI 为 `股票分析.pyz`。分析默认不保存文件，只在用户导出时写 CSV / JSON。证券表可独立更新。程序尚未接入复权因子；未实现历史回测、实盘交易、安装器或代码签名。Web、APK、IPA 和微信客户端尚未实现。
