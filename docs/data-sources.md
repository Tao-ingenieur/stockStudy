# 数据源适配约定

当前唯一实现为 `tdx`。候选来源包括标准 CSV、AKShare、Tushare 和 BaoStock；本次没有添加网络调用、密钥、账号或未经验证的兼容声明。

## 统一模型

每个适配器实现 `DailyBarSource`：

1. `securities()` 返回去重且稳定排序的 `Security(market, code)`。
2. `read_bars(security, limit)` 返回最多 `limit` 条日线，按日期升序排列。
3. `close()` 释放资源。

`market` 当前使用 `sh/sz/bj`，代码保留前导零。价格使用整数分，成交量使用股，成交额使用元。当前策略接受不复权日线。新来源必须明确复权方式、价格精度和数据单位；遇到不能无损表示的价格应扩展模型，而非静默截断。

适配器需要处理停牌、空记录、重复日期、字段缺失、上市退市、错误隔离和请求限制。不能把数据缺失等同于零价格。网络 API 的许可、费用、令牌和更新延迟在正式接入时核对；令牌不写入源码或 Git。

## 新来源的接入步骤

1. 在 `readers/` 添加适配器；不要把供应商 API 调用写进策略。
2. 添加确定性本地样例和单位转换测试，明确数据使用许可。
3. 在 `SOURCE_FACTORIES` 注册，更新 CLI 和 README 的状态。
4. 在真实样本上比对字段、复权与交易日语义，再开放为已支持来源。

CSV 候选字段为 `market,code,date,open,high,low,close,amount,volume`。这只是设计约定，当前还没有 CSV 行情导入命令。证券名称 CSV 属于元数据，与行情 CSV 是不同用途。
